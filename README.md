# Lil-c

General purpose (linux) C library with stuff like allocator system, dynamic arrays, hashmaps, hashsets, deques, dynamic strings, file-, string- and number-utilities.

# Building from source

Pre-built binaries are available in Releases.

This project uses the [gurd](https://github.com/Thepigcat76/gurd) build tool.

Here is how to build with gurd: [Building Gurd Project without Gurd](https://github.com/Thepigcat76/gurd/blob/main/README.md#building-gurd-project-without-gurd)

Make sure to pass in `--lib` while building!

Here is how to build without gurd: [Building Gurd Project with Gurd](https://github.com/Thepigcat76/gurd/blob/main/README.md#build-script)
